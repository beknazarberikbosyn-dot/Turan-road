# Turan Road — Тұран жолы

Интерактивное путешествие по природе и истории казахских земель. Игрок выбирает героя — батыра или путешественника — и масть коня, а затем скачет по карте Великой степи от горы Казыгурт до меловых скал Мангистау.

## Как устроено путешествие

Первая точка — **Туркестан**. После неё открывается вся степь, и игрок сам выбирает, куда скакать дальше: на карте видна сеть караванных дорог, а при нажатии на точку появляется карточка — кто там встретит, какое испытание ждёт и о чём можно узнать.

В каждой из 13 точек пять шагов:

1. **Знакомство** — встреча с местным жителем.
2. **Знания** — карточки с фактами: история, легенды, традиции, природа, животные и растения.
3. **Испытание** — экшен-мини-игра, своя для каждого места (за неё дают от 1 до 3 звёзд).
4. **Вопросы** — два коротких вопроса по фактам. Если ошибёшься, беркут Қыран подскажет.
5. **Тұмар-тас** — камень памяти: зажми его, пока не наполнится светом, и он перенесёт тебя в прошлое. Там можно нажимать на светящиеся точки прямо на картинке.

За каждую точку герой получает тұмар-артефакт, а все факты и звёзды сохраняются в журнале **Шежіре**.

## Особенности

- Главное меню с наклонённой картой и полётом сквозь облака после нажатия «Играть».
- Живая карта: по Шёлковому пути идёт караван, в Бетпакдале бегут сайгаки, у Алтын-Эмеля пасутся куланы, в Каспии ныряют тюлени, из озёр выпрыгивает рыба, по степи плывут тени облаков, а над героем кружит беркут.
- Настройки: яркость, громкость музыки и звуков, скорость текста, сброс прогресса.
- Вся музыка и звуки синтезируются в браузере (Web Audio API).
- Карта показывает ландшафт — моря, реки, горы, пустыни — без политических границ.
- Прогресс сохраняется в браузере (localStorage).
- Работает на компьютере и телефоне, без сборки и зависимостей.

## Запуск

Это статический сайт. Локально:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

### Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**. Через минуту сайт будет доступен по адресу `https://<имя-пользователя>.github.io/turan-road/`.

## Структура

```
index.html        — разметка: меню, карта, интерфейс
css/style.css     — оформление
js/data.js        — все точки маршрута: факты, задания, артефакты, сцены прошлого
js/geo.js         — природная карта (моря, реки, горы, пустыни)
js/map.js         — камера, перетаскивание, зум, маршрут, герой
js/hero.js        — герой на коне
js/games.js       — экшен-испытания
js/sprites.js     — звери, рыбы и предметы для испытаний и карты
js/scenes.js      — иллюстрации мест, портреты, артефакты
js/audio.js       — музыка и звуки
js/main.js        — логика игры
```

Чтобы добавить новую точку, допиши объект в массив `LOCS` в `js/data.js`. Испытание задаётся полем `game`, например `{ type: 'dig', skin: 'sand', items: ['coin', 'jug'], title: '…', intro: '…', how: '…' }`.
